# To Beyond

A dark Omarchy / Omalauncher theme: near-black space, icy blue text, and vivid red accents.

![To Beyond wallpaper](stitched-preview.jpg)

## Wallpaper

One widescreen wallpaper, **8192 × 4096 (2:1)**, made by stitching four images side by side in their original order. It is the theme’s only wallpaper and default background.

Artwork: [Dogan Ural — To beyond](https://x.com/doganuraldesign/status/2110745483547206034).
The artwork belongs to its original creator. No artwork license or endorsement is implied.

## Install

```sh
omarchy theme install https://github.com/cbarland/omarchy-to-beyond-theme
```


Clone or extract this theme into `~/.config/omarchy/themes/to-beyond`, then select **To Beyond** in the launcher’s theme picker. Choose its stitched wallpaper under Background.

Includes `colors.toml`, `icons.theme`, and the stitched wallpaper. Terminal colors are generated by Omarchy from the palette.
